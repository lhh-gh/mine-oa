# MineAdmin OA 系统 — 用户需求梳理文档（D1）

> 项目代号：MineOA
> 技术基线：MineAdmin 3.x（基于 Hyperf 3.x，PHP 8.2+）
> 版本：v0.1（初稿，待评审）
> 日期：2026-10-26

---

## 1. 项目背景与业务目标

### 1.1 背景

中小企业（目标规模 ≤ 500 人）日常办公依赖口头沟通、纸质单据或零散的微信群审批，
存在审批进度不透明、考勤统计困难、公告触达率低、文档版本混乱等问题。

### 1.2 业务目标

| 编号 | 目标 | 衡量指标 |
| --- | --- | --- |
| G1 | 审批全流程线上化 | 常用审批（请假/报销/采购/用章）100% 线上流转，平均审批耗时下降 50% |
| G2 | 考勤自动化 | 打卡、补卡、统计报表自动生成，HR 月度统计工时从 2 天降至 0.5 天 |
| G3 | 信息触达可量化 | 公告已读率可统计，重要公告触达率 ≥ 95% |
| G4 | 文档集中管理 | 部门文档统一存储、权限受控、可检索 |

### 1.3 非目标（本期不做）

- 复杂 BPMN 流程引擎（会签、条件分支后续版本演进）
- 薪资核算、绩效管理（与考勤联动，二期再评估）

## 2. 功能清单

### 2.1 复用 MineAdmin 内置能力（不重复开发）

| 模块 | 说明 |
| --- | --- |
| 用户管理 | 员工账号、部门归属、岗位 |
| RBAC 权限 | 角色、菜单权限、API 权限、数据权限（按部门隔离） |
| 操作日志 | 后台操作审计 |
| 附件上传 | 本地/OSS 存储驱动（文档中心在其上扩展） |

### 2.2 核心办公（审批流）—【核心】

| 功能 | 要点 |
| --- | --- |
| 审批模板配置 | 管理员可配置：模板名称、关联表单、审批节点序列（顺序审批，支持多人并行节点）、抄送人规则 |
| 发起审批 | 员工填写表单发起；表单字段：文本、数字、金额、日期、时间段、图片附件 |
| 审批操作 | 同意 / 驳回（驳回至发起人或上一节点，可配置）/ 转交 / 撤回（下一节点未处理前） |
| 审批提醒 | 待办产生时站内消息 + H5 推送提醒 |
| 审批记录 | 每一步操作留痕：操作人、时间、意见、耗时 |
| 我的申请 / 待我审批 / 我已审批 / 抄送我的 | 四个常用视图 |

### 2.3 考勤签到 —【核心】

| 功能 | 要点 |
| --- | --- |
| 打卡 | H5 端上班/下班打卡；支持 Wi-Fi / IP 范围校验（可选地理位置） |
| 考勤日历 | 个人出勤日历视图：正常/迟到/早退/缺卡/请假/节假日 |
| 补卡申请 | 走审批流模板，通过后自动修正考勤记录 |
| 排班与规则 | 工作日历（默认双休）、上下班时间、迟到早退阈值可配置 |
| 月度报表 | 按部门/个人统计：出勤天数、迟到次数、缺卡次数；支持导出 Excel |
| 数据联动 | 请假审批通过后自动写入考勤记录 |

### 2.4 公告与文档中心 —【核心】

| 功能 | 要点 |
| --- | --- |
| 公告发布 | 富文本公告，支持置顶、定时发布、指定部门范围 |
| 已读统计 | 每篇公告的已读/未读人员列表，未读可一键催办 |
| 站内消息中心 | 统一消息盒子：审批待办、公告、系统通知；未读角标 |
| 文档中心 | 目录树（按部门/类别）、上传下载、在线预览（Office 转 PDF）、权限受控 |

### 2.5 移动端（H5 + 小程序）—【核心】

采用 uni-app（Vue3）一套代码编译 H5 与微信小程序两端，审批核心功能双端一致：

| 能力 | H5 端 | 小程序端 |
| --- | --- | --- |
| 审批待办 / 发起 / 处理 | ✅ | ✅ |
| 打卡与考勤日历 | ✅ | ✅（可利用小程序定位能力做打卡围栏） |
| 公告阅读与消息中心 | ✅ | ✅ |
| 登录方式 | 账号密码 + 手机验证码 | 微信授权登录（code2session 绑定员工账号，首次绑定需手机号校验） |
| 消息提醒 | 站内消息 + 浏览器推送 | 订阅消息（Subscribe Message）推送审批待办提醒 |

> 小程序端一期限定**审批 + 考勤 + 公告阅读**三块高频能力，文档中心、后台管理类操作不进小程序（保持小程序轻量，降低审核与维护成本）。

## 3. 非功能需求

| 维度 | 要求 |
| --- | --- |
| 性能 | 并发用户 ≤ 100；审批/打卡接口 P95 < 500ms；早高峰打卡无雪崩 |
| 可用性 | 工作日 8:00-20:00 可用性 ≥ 99.5%；单点部署 + 每日备份 |
| 安全 | JWT 鉴权；操作/审批全留痕；敏感数据（手机号）脱敏展示；上传文件类型白名单；小程序服务端校验 code2session，禁止信任前端身份 |
| 兼容 | H5 适配主流手机浏览器与微信内置浏览器；小程序兼容微信基础库 ≥ 2.30 |
| 可维护 | 代码遵循 PSR-12；模块化目录；接口文档（Swagger）自动生成 |

---

## 4. 约束条件

- PHP ≥ 8.2，Swoole ≥ 5.0（MineAdmin 3.x 基线）
- MySQL 8.0 + Redis 6+
- 审批流采用自研状态机（顺序审批 + 并行会签节点），不引入外部工作流引擎
- 单体模块化部署（Hyperf 单进程组），不拆微服务
- 移动端采用 uni-app（Vue3）一套代码编译 H5 与微信小程序；后端为两端提供同一套 Api 接口
- 前端：后台 Vue3 + Element Plus（MineAdmin 自带）；移动端 uni-app（Vue3 + Vant 由编译平台适配）

## 5. 验收标准（一期）

1. 管理员可配置一个「请假审批」模板并完成一次完整流转：发起 → 审批 → 归档，全程有留痕（后台与移动端均可操作）。
2. 任意员工可在 H5 或小程序完成打卡，HR 可导出当月考勤报表。
3. 公告发布后可查看已读名单，未读一键催办。
4. 请假审批通过后，考勤日历自动显示对应请假状态。
5. 权限验证：普通员工无法访问 HR 报表菜单（RBAC + 数据权限）。
6. 小程序端：微信授权登录并绑定员工账号后，可收到审批待办订阅消息提醒并完成一次审批。
