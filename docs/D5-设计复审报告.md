## 3. 原复审决策的当前有效版本

此前多轮记录中出现的App/OA顶层模块、插件化、异常目录复数、单token API、移动用户固定USER200、
alova主链、公开公告白名单、migrations/oa、默认已验证等表述均已被本版替代。
保留原复审P0-1至P0-5、P1-1至P1-5、P2-1至P2-2及N1至N7的业务目标，按D9补足落地条件。

| 决策 | 当前有效版本 |

| 用户明确选择 | MineAdmin 3.2、unibest、OA不采用插件 |
| 目录 | App\Http\{Admin,Api} + Service/Repository/Model/Exception/Schema，各层OA子目录 |
| 原P0-1权限 | 员工角色、模板范围、资源参与者和数据策略共同授权，空范围明确拒绝 |
