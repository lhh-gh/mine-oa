## 1. 验证分层与证据

| 层 | 范围 | 环境 |
| --- | --- | --- |
| 文档一致性 | 路径/字段/错误码/权限点/阶段/表关系/配置来源 | 本地静态核对 |
| 单元 | 状态机合法转移、日期计算、DTO映射、快照与范围计算纯函数 | PHPUnit或Vitest，隔离数据 |
| 业务集成 | 正常员工请假、重提、抄送、打卡/补卡、消息消费、日结重算 | 专用MySQL8/Redis，明确标记的测试账号和单据 |
| 前端 | 组件、分页、生成路由、四Tab及表单字段映射 | web与mobile各自工具链 |
| 发布 | 迁移发现、首个菜单、两端产物、独立域名、重启/恢复/回退 | 隔离验收环境 |

每次结果记录版本/提交、环境、命令、结果、失败项与证据位置。设计完成不能替代运行结果。
所有样例使用隔离且明确标记的合成数据，不写入真实员工考勤、审批或统计结果。
权限相关项先做配置、授权逻辑静态复核与正常角色的数据口径核对。

## 3. 与现有测试设施对齐

后端autoload-dev为 `HyperfTests\`→tests/，因此新测试使用 `HyperfTests\OA\...`，不另建Tests映射。
纯状态机/纯函数继承PHPUnit TestCase，不初始化协程/数据库；业务HTTP集成可复用
`HyperfTests\HttpTestCase` 与已有 `RunTestsInCoroutine`。不在已运行的协程用例内再嵌套Swoole\Coroutine\run。

连接归还使用框架事务/协程defer及测试清理设施；每个用例回滚其测试事务或清理明确标记的数据。
引用类应为 `Hyperf\Context\ApplicationContext`；不得用`::class`表达式冒充连接释放。
后台任务测试显式传Actor/授权范围，不从HTTP CurrentUser读取。

正常状态转移的最小样板（依赖OA类完成后再加入tests/OA/Unit）：

```php
<?php

declare(strict_types=1);

namespace HyperfTests\OA\Unit;

use App\Service\OA\StateMachine\ProcessStatus;
use App\Service\OA\StateMachine\Transition;
use PHPUnit\Framework\TestCase;

final class TransitionTest extends TestCase
{
    public function testDraftCanSubmit(): void
    {
        self::assertSame(
            ProcessStatus::PENDING,
            Transition::go(ProcessStatus::DRAFT, 'SUBMIT'),
        );
    }
}
```

样板只是命名空间与测试环境约定，不代表目前存在可运行的OA测试。

## 4. 执行门禁（实现后）

后端在具有Swoole与MySQL8的Linux验收环境运行项目既有 `composer test` 与 `composer analyse`。
新增OA测试先定向运行，必要的业务集成通过后执行项目要求的检查；不向真实业务库运行种子或并发样例。
web使用 `pnpm lint:tsc` 与 `pnpm build`；如使用lint命令需注意当前eslint/stylelint脚本含自动修复行为。
mobile按AGENTS要求执行 `pnpm type-check`、`pnpm lint`、`pnpm test:run`，并构建H5/微信产物。

性能验收每阶段在相同固定数据规模记录并发、P50/P95、错误率和连接池等待；目标为并发≤100、
核心接口P95<500ms，未实测前不得标记性能通过。

## 5. oa:smoke待实现契约

| 项 | 行为 | 失败处理 |
| --- | --- | --- |
| 基础可用性 | 应用启动、MySQL与Redis连接、只读配置完整性 | 非0退出并记录脱敏原因 |
| 迁移与种子 | OA迁移已执行、精确菜单/角色/策略存在 | 非0退出 |
| 认证配置 | default/mobile配置字段、密钥引用与场景依赖接线静态一致 | 非0退出，不输出密钥 |
| 前端与路由 | 所发布静态产物及已注册OA入口存在 | 非0退出 |
| 消费进程 | 注册状态、心跳、READY最老年龄、DEAD数量 | 超阈值非0退出 |
| 私有附件 | private_oa目录/驱动可用且无公开映射配置 | 非0退出 |

命令只读、不自动创建真实请假/考勤记录。需要业务写入的全链路验收使用隔离测试环境和合成账号，结果单独归档。
健康端点 `/health` 待实现，返回基础探活，不暴露连接串或内部异常；运行态与配置检查应分别记录。
